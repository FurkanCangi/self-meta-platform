## Immutable online candidate protocol

After this code and its harnesses are committed, that exact commit becomes `B1-Candidate1`.

Run exactly once and in this order:

1. real B1 closed-choice provider preflight;
2. exact B1 Smoke8;
3. only if Smoke8 is 8/8, authoritative B1 Student40 once;
4. stop at the first critical failure;
5. no same-SHA rerun or same-day micro-patch loop.

The B1 semantic path is largely deterministic, so Smoke8 and Student40 may legitimately report zero provider calls. The preflight separately proves that the real provider and closed-choice schema work for an actually ambiguous turn.
